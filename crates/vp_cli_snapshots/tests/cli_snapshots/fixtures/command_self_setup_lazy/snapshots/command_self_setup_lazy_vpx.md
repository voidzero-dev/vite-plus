# command_self_setup_lazy_vpx

## `node verify.mjs vpx`

**→ expect-milestone:** `lazy-setup:verify:complete`

```
Fresh native setup completes without Node, pnpm, or a JavaScript payload
vpx uses explicit or project-local loaders without installing the global payload
vpx reports install failures and retries the global script loader on next use
Script and watch commands reuse the completed global payload
```

# command_self_setup_lazy_registry_retry

## `node verify.mjs registry`

**→ expect-milestone:** `lazy-setup:verify:complete`

```
Fresh native setup completes without Node, pnpm, or a JavaScript payload
Native setup retries preserve comments, authentication, and scoped registry settings
The registry is updated with missing or partial payloads and retained without an override
Retries do not install Node, pnpm, or complete a partial JavaScript payload
```

# command_version_local_tools

Resolve bundled tool versions from the local vite-plus package.

## `vp -V`

```
VITE+ - The Unified Toolchain for the Web

vp <version>

Local vite-plus:
  vite-plus  <version>

Tools:
  vite             <version>
  rolldown         <version>
  vitest           <version>
  oxfmt            <version>
  oxlint           <version>
  oxlint-tsgolint  <version>
  tsdown           <version>
```

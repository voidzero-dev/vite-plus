# migration_referenced_oxc_config_converted_consumer

Converting a package's inheritance must not remove JSON still used by the root script.

## `vpt write-file packages/app/.oxlintrc.json '{"extends":["../../.oxlintrc.json"],"rules":{"no-console":"error"}}'`

console.log('\''test'\'');
'`

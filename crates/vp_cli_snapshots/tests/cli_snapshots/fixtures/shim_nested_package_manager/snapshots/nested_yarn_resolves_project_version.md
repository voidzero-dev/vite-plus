# nested_yarn_resolves_project_version

## `vpt json-edit package.json packageManager yarn@4.12.0`


## `vp env on yarn`


## `npx --offline --call 'yarn --version'`

A nested shim installs the project Yarn on first use


## `npx --offline --call 'yarn --version'`

npx resolves the project Yarn without a system Yarn

```
4.12.0
```

## `npx --offline --call 'yarnpkg --version'`

The Yarn alias resolves the same project version

```
4.12.0
```

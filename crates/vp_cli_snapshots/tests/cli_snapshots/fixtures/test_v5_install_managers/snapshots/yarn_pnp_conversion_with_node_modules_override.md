# yarn_pnp_conversion_with_node_modules_override

Migration saves the project linker when the command has a temporary node-modules override.

## `vpt json-edit package.json packageManager yarn@4.12.0`


## `vpt write-file .yarnrc.yml 'nodeLinker: pnp
'`


## `vp install`


## `vpt stat-file .pnp.cjs --assert file`

```
.pnp.cjs: file
```

## `YARN_NODE_LINKER=node-modules vp migrate --no-interactive --no-hooks --no-agent --no-editor`
